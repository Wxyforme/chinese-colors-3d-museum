# 传统古色 · 3D 博物馆

一个**纯前端**的「中国传统色」数字博物馆：3D 第一人称漫游 + 色谱长卷 + 全屏观画 + 互动区，四视图单文件。
按策展方案分成**序厅 + 四个单元**：序厅（入口）→ 壹 · 色源・万物生 → 贰 · 物色・入人间（八角主厅）
→ 叁 · 绘事・绢上观（内厅，看画）→ 肆 · 感知・互动。
从**馆外甬道**起步，正对门楣匾额「传统古色」，顺着地面金色箭头走进去即可。

## 一句话启动

**双击项目根目录的 `启动服务器.bat`** —— 它会起好本地静态服务器，并**自动用默认浏览器打开
[`http://127.0.0.1:8899`](http://127.0.0.1:8899)**。

> 关闭那个黑色命令行窗口即停止服务器。
>
> 若上次的窗口没关，脚本检测到 8899 已在监听就**不重复启动**，只把浏览器打开。
>
> ⚠️ `启动服务器.bat` 是 **GBK(cp936) 编码 + CRLF 换行**，**请勿改存为 UTF-8**，也不要往里加
> `chcp 65001`。`cmd.exe` 按控制台代码页（简中系统为 936）解码批处理文件的字节：存成 UTF-8
> 会让窗口里中文全变乱码；而中途改代码页会让 cmd 解析后续行错位，连 `echo` 都被吃掉。
> 用记事本另存时选「ANSI」即为 GBK。

## 为什么之前 3D 渲染不出来（两个原因，都已修复）

1. **Three.js 依赖加载失败** —— 原代码从 `cdn.jsdelivr.net` 加载库，国内常被墙/重置，库拿不到整个
   3D 场景就初始化不了，页面永久卡在「正在布展 · 加载八色藏品」。
   ✅ **已修复**：把 three.js **本地化**到 `assets/vendor/three/`（r160），用 `importmap` 指向本地文件，
   **完全不依赖外网 CDN**，离线也能跑。
2. **`file://` 直接双击打开被 CORS 拦截** —— 页面用 `<script type="module">` + `import`，`.glb` 又是相对
   路径加载；双击用 `file://` 打开时浏览器会因跨域限制拒绝加载。
   ✅ **已修复**：走本地静态服务器（`tools/serve.py`），通过 `http://127.0.0.1:8899` 访问。

> ⚠️ 所以**不要靠双击 `index.html` 打开**，必须走 `启动服务器.bat`（或任一静态服务器）。

### 配乐

一首《高山流水》（古琴）两处共用：`ASSETS.bgm` 与 `ASSETS.painting.audio` 都指向
`assets/audio/bgm.mp3`。馆内那处是 `<audio loop>`（循环）；观画那处是 `<audio controls>`
播放器，不自动循环。**想让两处放不同的曲子**：把 `ASSETS.painting.audio` 改成一个新文件名，
再把文件放进 `assets/audio/` 即可。

**两个 `<audio>` 都是 `preload="none"`，页面加载时不取音频**：馆内那首等观众第一次点击画面
才下载（备好即起播），观画那首等打开观画视图才下载。线上带宽被限速（实测单流 20~60 KB/s），
配乐若跟 8 个模型抢管子，实测会让加载遮罩从 478 秒拖到 800 秒 —— 所以别改回 `preload="auto"`。

`bgm.mp3` 是 1.03 MB / 90 秒 / 96 kbps，由母带（8.0 MB / 210 秒 / 320 kbps）取前 90 秒重编码而来；
母带不在仓库里（放在 gitignore 的 `.workbuddy/_src/audio/`，不会发布，也不拖慢 Pages）。
重编码命令与「为什么降到 96 kbps」见 `assets/audio/README.txt`。

## 操作说明

页面含四个视图：**3D 博物馆**（默认）、**色谱长卷**、**观画**、**互动**（肆区那三块板进去）。

### 3D 博物馆 · 参观路线

```
甬道 → 序厅（前言展板 + 月曼清游图长墙 + 落地双面「平面导览图」 + 剖面游览图）
        ├─ 左手边 → 壹 · 色源・万物生（按加工流程走一圈：原料墙 → 工序台 → 成品柜）
        └─ 直走   → 八角主厅 = 贰 · 物色・入人间（8 座一物一柜的定制展柜）
                    ├─ 再直走 → 内厅 = 叁 · 绘事・绢上观（古画 + 8 色展牌）
                    │            └─ 右手边 → 肆 · 感知・互动（色卡墙 / 互动屏 / 留言墙）
                    └─ …
```

> **地上那条约 0.44m 宽的金色虚线就是参观动线**，转角与汇合处铺着箭头（八角主厅里是一圈
> 逆时针环线 + 切向箭头）。箭头指哪儿就往哪儿走，三个展厅里的三段路线分别对应三块导视牌
> 「甲 原料 / 乙 工艺 / 丙 成品」。

- **鼠标移到展品 / 画作上** → 光标变手型、展台亮起高亮环，光标旁浮出「**点击进入卷轴**」
- **左键点击展品** → 展开该颜色的卷轴科普段　|　**左键点击古画或内厅 8 块色牌** → 进入**观画**视图
- **序厅「前言」展板**读两段：上一段讲这八个名字本是古人给颜色起的温柔雅称，
  下一段交代**为什么只挑这八色**（「少而深」代替「多而浅」，兼顾正色与间色、冷与暖、
  矿物与植物来源，覆盖蓝紫黄三系，有样本代表性、并非完整色谱）—— 这是整个展厅的选色口径
- **壹区（色源）**：原料墙上的每一块原料、四座成品柜里的每个标本位、四座工序台**也都点得动** ——
  点开是一张「原料卡 / 工序卡」（原料卡上有 AI 生成的原料图与产地、水飞或浸染的流程，以及一首古籍摘句）
- **肆区（互动）**：色卡墙下部的「补录七色」带、互动屏、留言墙**三块板点得动**，点任一块进入**互动视图**
- **点击空地**（或按 **F**，或点顶栏「**进入漫游**」）→ 进入第一人称漫游（锁定鼠标）
- **W / A / S / D** 移动，**鼠标**转视角
- **顶部 8 个色点** → 瞬移到对应展台　|　**顶栏 ♪** → 开关馆内配乐（缺文件时自动置灰）

> **漫游中也是「左键直达」**：走近展品时，屏幕正中出现准星与提示
> 「点击鼠标左键 · 进入卷轴」，**直接按左键就进卷轴/观画，不必先按 ESC 解锁**；
> 壹区、肆区里准星同样会变——对着原料是「查看这件原料」、对着工序台是「查看这道工序」、
> 对着肆区三块板是「进入互动区」。
> 左键点空地则退出漫游、把光标还回来。
>（注：ESC 退出鼠标锁定是浏览器的固有行为，网页改不掉，但它已经不是必经步骤了。）
>
> **返回展厅后仍是漫游态**：你大概是漫游走近了才点开它的，所以从卷轴 / 观画 / 互动区回来时，
> 若进去之前正在漫游，会把漫游还给你 —— 回来直接按 **W** 就能走开，不必先找空地。
> **贴着一块板站着、满屏都是可点对象时**，正是靠这条和 **F 键 / 顶栏「进入漫游」**才出得来。

### 互动视图（肆 · 感知・互动）

从肆区任一展板进去，四个标签页：

- **① 八色答题** —— 十道关于本馆八色的题，交卷即给分并逐题给解析，可重做。
- **② 填色卡** —— **一幅八色山水**（程序化画的芥子园味线稿：天 / 月 / 远山 / 主峰 / 坡石 /
  江水 / 松 / 秋林八个可填区，未填时每个部位上写着它「宜」哪一支色）。鼠标掠过部位会报
  「部位名 ＋ 宜什么色」，选一支颜色点上去即可；**「导出 PNG」**存一张 3600×2480 的图。
- **③ 留言板** —— 写一句关于颜色的话（**可署名、可匿名**，40 字以内），贴上去就会出现在
  展厅那面**留言墙**上；想删就删，墙面同步更新。留言存在浏览器本地（`localStorage`），
  便签的位置、大小、浓淡都由 id 派生 —— **同一批留言每次都是同一面墙，刷新不会乱跳**。
- **④ 续色 · 结语** —— 八色之外的「补录七色」（石绿 / 朱砂 / 赭石 / 花青 / 藤黄 / 胭脂 / 檀色）
  与收尾结语。这部分是**通用色谱近似值，不是文物取样**。

**Esc** 或左上角「‹ 返回展厅」回 3D 展厅。

### 观画 / 色谱长卷

- 观画：点右侧 8 个色名，读出该色的释义与**文字**位置（如「霁蓝 —— 画中栏杆、深色衣袍」）；
  右下播放器放观画配乐；**右上「返回展厅」**回展厅。
  ⚠️ 画面上的白点热点（`ASSETS.painting.spots`）**还没配**（全 `null`），所以图上不会出现可点白点、
  也不做高亮 —— 位置只能以文字给出，别照着旧说明去找白点。
- 长卷：**← / →** 或键盘左右方向键翻段；拖动或横向滚动自由浏览；顶部色点直达该色段；
  **左下角的「‹ 返回博物馆」**回 3D 展厅。
- 长卷每段的「诗词注记」卡：诗句**竖排两列**（按「，」分列，上句在左、下句在右，署名在最右），
  字号随卡片实际高度缩放（`min(20px, 10cqh)`，`.poem-wrap` 是尺寸查询容器）—— 窄窗口下
  卡片变矮时字号自动收小、署名自动折成两列，不会冲出卡片。详见 `HANDOFF.md` §11 第 31 条。

## 备注

- **three.js 已本地化**到 `assets/vendor/three/`（r160），`index.html` 的 `importmap` 指向本地文件。
  不要再改回 `cdn.jsdelivr.net` / `unpkg.com` —— 那是「黑屏加载不完」的历史原因。
- 8 个展台**各有真模型**：`assets/models/` 里 8 个 `.glb` 齐全（袍类 4 件：月白 / 石青 / 藕合 / 杏黄；
  花篮 松花 / 盘 霁蓝 / 帛书 苍黄 / 罐 黛蓝），每个 3 万面、贴图 1024² JPEG。
  袍类另有**程序化降级物** `buildGarment()`（旋成型的清式袍服）：只在对应的 `.glb` 取不到时启用，
  与真模型同口径归一化后置入立柜 —— 所以删了模型文件也**不会空展台**。
- **壹区不加载任何模型**（纯程序化生成），按**处理颜料的流程**分三段走一圈：
  **① 原料（西墙）** 通长标本墙分两段 —— 北半「石色 · 矿石研磨」、南半「水色 · 草木浸出」；
  **② 工艺（北墙）** 4 座工序台（粉碎 · 石臼 → 水飞 · 陶盆 → 沉淀分级 · 三只玻璃小缸 → 晾干 · 竹匾收八色）
  ＋ 上方「从石头到颜色」六道工序流程图 ＋ 左端展词板「色从哪里来」；
  **③ 成品（南墙）** 4 座地平矮展柜（罩顶 1.17m，站着俯视、不用弯腰），东 2 柜石色、西 2 柜水色。
  展品分两类分形制：**石色**＝矿石原石 / 矿粒 / 色粉；**水色**＝干料（槐米串 / 栀子果 / 苏木木屑 / 蓼蓝束）/
  粗碎料 / 色粉 + 一方**染色绢小样**（颜色只在第 ③ 层出现 —— 颜色是磨出来、煮出来的）。
  灯光是 3000–4000K 中性白光的**斜侧掠射**，**没有彩色光、没有发光特效**；展柜玻璃带一层很淡的环境反光。
- 每座展台的**展柜按器物定制**（贰 · 物色）：4 件袍类用低倾角长条立柜、花篮用八边形地平柜、盘用圆形地平斜柜、
  帛书用长条斜面案、罐用方正独立柜；文物按实测尺寸缩放贴底置入柜内。
- 四座「地平」柜（花篮 / 盘 / 帛书 / 罐）**整柜站在 0.55m 高的台座上**，文物底面抬到 0.77~0.93m，
  **参观者不必弯腰**；台座束腰刻云纹与龙首相间的**浅浮雕**（同色系、起伏只有 2cm 级，远看素净）。
- 资源都已压过体积（主视觉/纹理 `.png` → `.jpg`；`.glb` 内嵌的 4096² PNG 贴图 → 1024² JPEG，
  `python -I tools/shrink_glb.py assets/models/xxx.glb`）。**新出一批模型后务必先压再提交** ——
  GitHub Pages 对大文件限速到约 35KB/s，16MB 的模型能下 3 分钟，访客会看到缺器物的展厅。
  压完用 `python -I tools/glb_info.py assets/models/*.glb` 复核包围盒 / 面数未变。
- 若某个 `.glb` 加载失败，该展台自动降级为占位展品，**不会卡住加载遮罩**。
- 改完 `index.html` 后先做个不依赖浏览器的语法体检：把 `<script type="module">` 里的源码抠出来存成
  `.mjs`，跑一次 `node --check`，能拦住语法错。**但它抓不到运行期的「整页白屏」**（顶层重名声明、
  `const` 的 TDZ、把 `Object3D` 的属性当方法调用等），**所以大改之后一定要在浏览器里真看一眼**
  （或按 `HANDOFF.md` §8 起无头 Edge + `tools/cdp_shot.mjs` 抓控制台）。
- 本地服务器（`tools/serve.py`）会发 `Cache-Control: no-store`，**改完刷新即可**。若页面仍是旧版，
  在那个标签页按 **Ctrl+F5**，并确认地址栏是 `127.0.0.1:8899`。
- **一眼判断有没有加载到最新版**：看标签页标题末尾的版本戳（当前 `[b37-local]`）。
