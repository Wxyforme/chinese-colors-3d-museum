填色卡「换图槽位」—— 这个目录是空的，空着就对了
================================================

互动区第 ② 页的「八色山水」填色卡，现在是 **canvas 程序化画出来的**
（见 index.html 的 CARD_REGIONS 一带：天 / 月 / 远山 / 主峰 / 坡石 / 江水 / 松 / 秋林
八个可填区，各有自己的多边形与墨线）。**页面不读这个目录里的任何文件**，
所以这里没有东西也不会报错、不会白屏。

为什么当初没放一张现成的国画线稿
--------------------------------
《更新模块/润色意见.txt》第 4 条的原话是「互动区卡图填色替换成其他图（有美感的图）」，
后来口头补充成「分色线稿你在网上找一个简易山水画，偏国风一些的」。
实测这条路走不通：
  · commons.wikimedia.org 的 curl 20 秒超时（国内网络）；
  · WebFetch 对 Commons 返回「无法验证域名」，而且它只回文字、拿不到图片字节；
  · 古籍扫描单页 2~5MB，GitHub Pages 线上实测限速约 35KB/s —— 访客要等一两分钟，
    与项目「资源必须压体积」的做法相冲。
所以改成程序化画：零依赖、可离线、体积为 0，而且**填色区与墨线严丝合缝**
（下载来的画做不到这点，色块一定会盖到线上）。

真想换成一张现成的线稿
----------------------
光把图片丢进来是**不够的**，也不建议只丢图 —— 那样不会有任何变化。

要换得走两步（都在 index.html 里）：
  1. 把图放进来，命名 `shan-shui-lines.png`（或别的名字，记得同步改代码）；
  2. **按这张图重新描 8 条 `poly`**：`CARD_REGIONS` 每项的顶点表要照着新图的
     天 / 月 / 远山 / 主峰 / 坡石 / 江水 / 松 / 秋林 逐个描一遍，
     并相应调整 `lab`（未填时写部位名的那一点）与 `ink`（这一区的墨线画法）。
     设计空间是 1600×1000，顶点直接写这个坐标系里的数就行。

  只做第 1 步、不做第 2 步的话：点上去会填到**错误的位置**（还在按老多边形算命中），
  比不换更糟 —— 所以这一步不能省。
